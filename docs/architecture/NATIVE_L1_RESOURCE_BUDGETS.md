# Resource budgets and measurement methodology — Task 017

**All figures below are proposed experimental controls/targets, not measured Genesis capabilities or native protocol limits.** Existing Experiment 001/002 caps stay unchanged. Numeric controls bound a disposable comparison; product-level latency, throughput, fees and device suitability remain unresolved until measurements and use-case evidence exist.

Profiles: **R** ordinary-computer reference process; **L** constrained-client proxy; **S** remote link simulation. A measured L process is not evidence that real flight/vehicle/embedded firmware fits its hardware. Satellites need not store full state or validate every transaction. [Workloads](NATIVE_L1_WORKLOADS.md) bind B1–B9; [experiment](NATIVE_L1_NEXT_EXPERIMENT.md) fixes run counts and success criteria.

KiB/MiB/GiB mean powers of 1024. Physical memory/storage/disk-cache counters are not interchangeable. A wall timeout caused by host contention cannot be reclassified as an invariant failure or silently rerun away; retain it and mark cause unknown unless demonstrated.

## Comparable measurements

Pin source versions, host/runtime/compiler, cryptographic library, deterministic codec, storage format/durability and instrumentation **before running**. Ordinary sequential conformance is the baseline; parallel scheduling is a separate experiment factor. Flush journals with an explicitly documented durability contract, and count that I/O. Collect monotonic wall/CPU time, peak RSS, disk growth, bytes, signature counts, state reads/writes, structural conflicts and reconstruction attempts. Compare accepted logical intents and verified outcomes, not raw envelope TPS or vendor gas schedules. Do not subtract crypto, witness construction or indexing overhead merely because one model needs more of it.

Warm-up: one unscored run per model, then three repetitions with identical manifest/order; preserve cold-start separately. Predeclare operating-system page-cache policy; report both warm and cold if claiming either. Hardware tiers and link classes are exploration dimensions; do not cross-combine every tier by default and exceed B9. Required budget profiles are specified in the [next experiment](NATIVE_L1_NEXT_EXPERIMENT.md); optional sweeps need a bounded manifest before execution.

Pass safety independently of speed. Mandatory structural/attempt bounds must hold. Missing the containment ceilings yields HOLD for that configuration; repeated measured excess after independent diagnosis can deprioritize it for the declared workload, not disprove its entire state-model family. Latency comparisons need identical inclusion/finality semantics; do not give an owned-object fast path credit for avoiding required shared-grant ordering.

Unresolved product budgets: actual validator/node minimums, transaction proof sizes, independent finality-verification cost, long-term storage and pruning, link-energy budget, human/vehicle deadline requirements and sustainable real fees. Resolve these through hardware/use-case measurement and proof/consensus design before a native devnet. Synthetic throughput is not genuine demand.
