## Highest-value question

Can accounts, objects and extended UTXO enforce identical cumulative delegated principal/fee authority while recovering interrupted intents, **without changing semantics or hiding an indexer, custodian or finality service**? This directly targets A-03/A-04 and reveals A-06/A-09 costs before building a network. Competing hypotheses: any model suffices; explicit resource ownership materially helps; durable replay/evidence requirements dominate all models; none meets the bounded profile. No preferred winner.

This experiment can establish finite semantic/model conformance and comparative local overhead. It cannot establish permissionless consensus, real light-client security, physical truth, useful-work scarcity, economic demand or production VM performance.

## Freeze manifest before authorization/execution

Deliver a reviewable corpus and schema vectors first: fixed network/service/actor IDs, public keys only, canonical CBOR and intent/terms digests, signed payloads, starting balances, operation arrays, grant versions/limits, fees, event order/time, expected projections and client observations. Fixture root balances are 1,000 units; provider/direct-client balances are 100; all actors and fee sinks are listed. Grant caps/prices override only as stated in workloads. No external funding/issuance. The W08 stress override uses root balance 10,000, total principal reserve 3,000 and fee reserve 3,000; delegate/provider own balances remain 100. For any deliberate insufficient-balance test, the manifest gives the different starting balance explicitly.

Use the same independent mathematical transition oracle and complete projected owner/grant/intent/agreement/credit states. Each adapter has distinct account, object/version or spend/output semantics; every helper registry and atomicity assumption is visible and metered. No EVM requirement, P2P nodes, consensus implementation, deployed wallets, monetary policy, network discovery or real device connection is necessary. An existing EVM trace can supply a read-only consent/accounting control; general native equivalence must not be inferred from it.

Pins/dependencies, exact adapter schemas/transport-reference encodings, journal crash points, golden projections and replay retention must be frozen in that later task before measurements. Their absence is **HOLD**, not license to improvise during a run. Task 017 supplies the common logical schema, not an executable dependency lock or a proof format.

## Mandatory corpus and schedules

| Corpus | Required cases / reproducible construction |
| --- | --- |
| W01–W08 | One success/control and one negative/recovery trace for each; use the explicit amounts/deadlines/outcomes in workloads. Include all I1–I8 assertions after every step. |
| Boundary cases | For principal/fee/size limit test limit-1, limit, limit+1; for fund/claim/grant expiry test time-1/equality/+1. For result include 0, 18, wrong sum, and two max-uint64 operands; encode wide result exactly as ASR. No overflow wraps. |
| Ordering/concurrency | For two spends sharing cap20, prices12+12: both orders, valid winner only once; disjoint grants with same aggregate resources as control. Revoke/spend and claim/refund both orders at legal times; actor-free deadline passage retains funded state. |
| Crash/recovery | Crash at each ASR journal/sign/submit/include/credit boundary; lost reply, duplicate wrapper, stale nonce/object/input, journal snapshot replay, recovery queried twice and unavailable evidence. Collect same credit twice; never fresh logical intent on unknown outcome. |
| Evidence faults | Single-field changes in network/anchor/intent/owner/fees/state/version; matching but stale observations; O2 prefinal rollback and O3 purported-final contradiction. Finality oracle is explicitly trusted in positive controls and attacked in negative observations. |
| Authority compromise | Wrong signer/recipient/purpose, grant version/epoch, replay/network mismatch, rotation/revoke, concurrent fee exhaustion, root balance isolated from G. In-scope stolen-delegate spend succeeds only within cap and must be labeled expected limitation. |
| Bounded stress | Ten, 100 and 1,000 attempted logical actions; up to32 clients, disjoint/half/all-shared grant state; request/recovery/observer bytes all counted. Deliberately invalid signatures/parsers are counted attempts too. |

For two-action races enumerate both permutations; for three-action races enumerate all six. No claim of exhaustive global interleaving coverage. Stress generator must be specified rather than depend on a language RNG: for indices i=0..n-1, assign actor i modulo clientCount, action Transfer for even i and Fund for odd i, prices 1+(i modulo 3), and workload-correct terms. Produce disjoint, half-shared and shared grants by manifest assignments; half-shared means first half of actors share one root grant and the rest have disjoint grants. Here n counts *all* delivered actions, including grant setup: reserve k setup slots and generate n-k Transfer/Fund actions. Required stress pairings are (n=10,clients=1), (100,8), (1,000,32), each with three sharing patterns; do not require 32 setup grants inside a 10-action trace. Half-shared coalesces the first floor(clientCount/2) actors’ per-actor allocations into one grant, leaving the remaining allocations disjoint; the one-client case degenerates to the same control. Stress actions are all included at logical time 1 with deadlines 10/20; this prevents workload size alone causing expiry. Stress ends with funding still locked; it measures admission/funding cost, not completed-service throughput (terminal/collection cases are separately mandatory). Across sharing/concurrency variants, one H and the same 32 delegate identities always exist; only the active subset and partitioning changes. Disjoint grants divide P/F by active client count using quotient and lowest-ID remainder assignment; shared grants reserve the same aggregate P/F, and half-shared partitions that same total between groups. Creation fees and all inactive principal balances remain in accounting. No reward for splitting identities. Independently owned roots are a separate W08 control with the same aggregate reserve/balance total, specified in the manifest, not mixed into the shared-root result. Compare structural conflicts separately from canonical semantic rejects.

Bounded plan: at most 30 base traces/configurations/model plus one warm-up and three measured repetitions (<=91 runs/model). Pack boundary/crash cases into reset-delimited base traces of <=1,000 actions; all mandatory subcases need named coverage. Three stress sizes and three sharing patterns are included in the 30, not additional unlimited batches. Fixed scheduler order is ascending actor/sequence in a control; race/blackout traces override explicitly. Baseline R and O1 mandatory; O2/O3 and W06 delay classes are mandatory fault traces. L=128 MiB with 32 pending intents and S=10 KiB/s are mandatory proxy configurations within the same run cap; other tiers are optional, explicitly bounded extensions. If necessary cases cannot fit the run plan, revise and review the manifest before execution; do not omit cases silently.

## Acceptance and interpretation

| Decision | Measurable criterion |
| --- | --- |
| FAIL candidate *configuration* | Any I1–I8 financial/authority violation, logical duplicate fee/payment, wrong-owner credit, invalid result acceptance, contradicted evidence promoted to final success, or hidden unmetered infrastructure. Publish minimal failing trace. |
| HOLD | Missing schema/vector/proof premise, unavailable measurements, timeout/budget excess, unsupported client tier or uncompleted mandatory corpus. No silent cap increases or dropped failures. |
| BOUNDED MODEL PASS | Every mandatory trace produces the oracle projection and intended client classification, repeated runs agree, all resource/attempt ceilings hold and artifacts reproduce on a second clean environment. Logical state equality matters, not identical internal roots. |
| Prioritize/deprioritize for next study | Only after safety: compare measured total cost, bytes/state growth, structural conflicts and recovery overhead at equal semantics/resources. Require direction consistent across three repeats and report range; no significance or global superiority claim from three samples. |

Expected Unknown/refund/halt outcomes are passes only when explicitly prescribed, not substitutes for success controls. O1 timely uncontended controls resolve within 10 logical ticks. No inclusion promise during indefinite blackout. A single failed adapter does not eliminate its state-model family: require independent diagnosis showing an unavoidable mismatch under the agreed model/constraints, not a repairable bug or different VM choice. All three, several or no candidates may survive.

Artifacts: public manifest/hash, reviewed dependency/source identities, golden byte/digest vectors, ordered actions and fault schedules, state projections/intent outcomes, budget counters, journal phase markers, observation classifications, per-run CPU/RSS/disk/bytes/retry/timing metrics and all failures. No private keys or raw signed transaction material in public logs. Independently authored checks must not share candidate state mutation code. Reproduction commands and exact corpus generator belong to the authorized experiment's report; no experiment is claimed executed here.
